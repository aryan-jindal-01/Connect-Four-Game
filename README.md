# 🎮 Connect Four Game

A modern and responsive Connect Four Game built using **HTML, CSS, and JavaScript**.

## 🌐 Live Demo

👉 https://connect-four-game-victus.netlify.app/

## 📂 GitHub Repository

👉 https://github.com/aryan-jindal-01/Connect-Four-Game

---

## ✨ Features

- 🎮 Two Player Connect Four Game
- 🏆 Winner Detection
- 🎉 Confetti Celebration
- 📊 Live Scoreboard
- 🔄 Restart Game
- 🆕 New Game
- 🌙 Dark / Light Theme
- 📱 Fully Responsive Design
- ⚡ Smooth Coin Drop Animation
- 🎨 Modern Glassmorphism UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/aryan-jindal-01/Connect-Four-Game.git
```

2. Open the project folder

3. Run `index.html` using Live Server
